# Demo Molina de Aragón

Objetivo: enseñar ADV ARCHON como copiloto urbanístico para una consulta municipal realista, local-first y prudente.

## Guion de demo

1. Abrir ADV ARCHON Studio.
2. Seleccionar o crear el expediente `DEMO - Consulta urbanística — Molina de Aragón`.
3. Revisar el bloque `Planeamiento aplicable`.
4. Mostrar que el sistema distingue:
   - dato oficial consultado;
   - inferencia preliminar de ARCHON;
   - validación técnica pendiente.
5. Exportar el informe PDF.

## Mensaje comercial

ADV ARCHON no promete certeza jurídica automática. Ordena la primera revisión, consulta fuentes oficiales, detecta riesgos y prepara un informe que un arquitecto puede revisar antes de hablar con cliente o Ayuntamiento.

## Qué debe verse en el informe

- Tipo de planeamiento: Normas Subsidiarias.
- Estado: preliminar.
- Fuente oficial: Ayuntamiento de Molina de Aragón.
- Advertencia: la ordenanza exacta requiere cruce con planos o validación municipal.
- Checks sectoriales: Catastro, inundabilidad, Natura, Costas no aplicable y carreteras.

## Límites de la demo

Los datos de parcela son demostrativos. La app no debe presentarlos como expediente profesional real ni como informe municipal vinculante.
