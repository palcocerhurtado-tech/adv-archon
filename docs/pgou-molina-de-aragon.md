# Planeamiento municipal — Molina de Aragón

Estado en ADV ARCHON: **preliminar**.

Molina de Aragón se integra como municipio con **Normas Subsidiarias de Planeamiento**, no como PGOU ordinario. El paquete local de ADV ARCHON usa fuentes oficiales públicas para orientar una consulta inicial, pero no sustituye el cruce con planos, fichas o visor municipal.

## Fuentes oficiales

- Ayuntamiento de Molina de Aragón — Urbanismo: https://molinadearagon.es/ayuntamiento/urbanismo/
- Texto refundido LOTAU Castilla-La Mancha, Decreto Legislativo 1/2023: https://www.boe.es/buscar/act.php?id=DOCM-q-2023-90054
- Portal de normativa urbanística de Castilla-La Mancha: https://vivienda.castillalamancha.es/node/397

## Cómo lo usa ARCHON

1. Indexa una semilla local curada con metadatos, fuente y advertencia.
2. Busca indicios textuales de clasificación, calificación, ordenanza, usos y parámetros.
3. Marca la zonificación como **preliminar** y exige cruce con plano o validación municipal.
4. Incluye una sección específica en el PDF: `Planeamiento aplicable — Molina de Aragón`.

## Advertencia de uso

La identificación exacta de una ordenanza de parcela no queda resuelta con texto. Debe validarse con documentación gráfica municipal, informe urbanístico o criterio técnico del Ayuntamiento antes de emitir una conclusión profesional.
